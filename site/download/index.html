Install in four steps

  1. Get the code. Download the ZIP and unpack it, or clone with Git:
    git clone https://github.com/Hudmebac/heliosrea.git
  2. Open the folder.
    cd heliosrea
  3. Start the room. On Windows run REA.bat. On any OS run:
    python rea/server.py
  4. Open the console. Visit http://127.0.0.1:4711/. The server binds to loopback only.
Before your first run: you need Python 3.10 or newer on your PATH. Nothing is installed with pip, and no account or key is needed. The console writes dossiers to rea/data/ on your machine.

What to do first

Read the short start route, then run one investigation against a small folder you own. Open Improve, write one outcome, and let the crew choose a move. The plan is a draft; the patch is applied only when you confirm it.

Safety and limits

Authorised targets only

Only inspect systems you own or have written permission to assess. The console refuses unauthorised investigations and blocks fixture or demo targets from publication.

Reversible by design

Automatic execution is limited to software or web plans on a clean local git work tree. Verification failure reverses the patch, and every applied plan can be rolled back.
