How to read the ledger

A signal is not automatically a finding. An empty result is a fact about the target. An error is a route for the next run. The status matters as much as the result.

Why empty and error stay in

Hiding a negative result makes the remaining evidence look stronger than it is. The appendix keeps the full ledger so a reader can see what was not found as well as what was.

What to run next

Choose the next question from the empty and error rows. Re-run only when the target or method changed, and record the reason for the retry.

A probe ledger is an audit trail. It is not a scorecard and it does not promise complete coverage.
