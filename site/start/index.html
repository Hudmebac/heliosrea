Ten short briefs. One evidence standard.

Ten narrated, captioned visual explainers generated from the real dossier. The series uses three local Windows OneCore voices in ten presenter treatments, with original diagrams and an original ambient bed. They are a door into the evidence, not a replacement for it.

All ten field notes →

What the series is

  • Ten original visual briefs from dossier REA-20261121-afd06c73-83835.
  • Different subjects, card accents and presenter treatments.
  • A local synthetic voice in each note, with player mute controls.
  • An original ambient bed under every voice.
  • A pointer to the receipt, the fact files and the limits.

What it is not

  • It is not a recorded teardown or a client case study.
  • It is not ten different people; it is three local voices treated ten ways.
  • It does not use third-party footage, music, audio or branding.

How to move through the room

Read, check, then go deeper

The full method →
  1. Read the claim. Start with the latest evidence file or one fact file. Do not start with the appendix.
  2. Check the receipt. Open the locator, the confidence and the dossier hash. The appendix is where the empty probes live.
  3. Learn the method. The field guides turn the same sequence into a checklist you can use on an authorised target.
  4. Choose a next step. Watch one field note, read the proof page, or request the monthly notes. No step requires a donation.
